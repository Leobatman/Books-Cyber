# 11 — Digital Forensics

Computer forensics, evidence handling, incident investigation, and data recovery.

Digital forensics is essential for understanding what happened after a breach, preserving evidence for legal proceedings, and supporting incident response. While this collection has a limited number of dedicated forensics books, the CHFI materials from EC-Council provide solid coverage.

---

## Books in This Category

#### CHFI v01: Computer Forensics Investigation Procedures & Response
- **Author:** EC-Council
- **Level:** Intermediate
- **Priority:** ⭐⭐⭐⭐
- **Key Topics:** Forensic investigation methodology, evidence collection and preservation, chain of custody, first responder procedures, legal considerations
- **[Study Notes](../notes/chfi-v01-forensics.md)**

#### CHFI v03: Computer Forensics Investigating Data & Image Files
- **Author:** EC-Council
- **Level:** Intermediate
- **Priority:** ⭐⭐⭐
- **Key Topics:** File system analysis, data carving, image file forensics, steganography detection, metadata analysis
