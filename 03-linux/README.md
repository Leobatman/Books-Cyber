# 03 — Linux

Linux administration, command-line proficiency, and Bash scripting for security professionals.

Linux is the foundation of offensive security. Kali Linux is built on Debian, most servers run Linux, and most security tools are designed for it. Proficiency here is non-negotiable.

---

## Recommended Study Order

1. **Linux Basics for Hackers** — Purpose-built for security learners. Start here.
2. **CompTIA Linux+ Study Guide** — Broader admin knowledge for deeper understanding.
3. **Bash Notes for Professionals** — Quick reference for scripting patterns.
4. **Linux Administration Cookbook** — For when you need server management skills.
