# 10 — Mobile & IoT Hacking

Mobile application security, IoT device exploitation, container security, and platform-specific attacks.

As computing expands beyond traditional desktops and servers, new attack surfaces emerge. This category covers hacking mobile apps (Android, iOS), IoT devices, containers (Kubernetes), VoIP systems, and platform-specific exploitation.

---

## Recommended Study Order

### Mobile Focus
1. **Mobile Application Penetration Testing** — Methodology overview for both platforms.
2. **The Mobile Application Hacker's Handbook** — Deep dive into iOS & Android app security.
3. **Android Hacker's Handbook** — Android-specific internals and exploitation.
4. **iOS Hacker's Handbook** — iOS-specific exploitation and jailbreak techniques.

### IoT/Container Focus
1. **The IoT Hacker's Handbook** — IoT architecture, firmware, radio, hardware.
2. **Hacking Kubernetes** — Container and orchestration security.
