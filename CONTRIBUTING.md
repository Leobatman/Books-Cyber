# Contributing

Thank you for your interest in contributing to this cybersecurity study resource.

## How to Contribute

### Adding a New Book

1. Fork this repository.
2. Create a new branch: `git checkout -b add/book-name`.
3. Add the book entry to the appropriate category `README.md` following the existing format.
4. If the book is rated ⭐⭐⭐ or higher, create a study note in `notes/` using the [note template](#note-template) below.
5. Update `CATALOG.md` with the new entry.
6. Submit a pull request with a clear description.

### Improving Existing Notes

- Fix factual errors or typos.
- Add missing tool references or prerequisites.
- Improve study recommendations based on your experience.
- Add official links that may be missing.

### Suggesting Study Paths

If you have completed a certification or career path and have insights on book ordering, open an issue with:
- Your background/experience level.
- The path you followed.
- Which books were most valuable and why.

## Note Template

When creating a new book note, use this structure:

```markdown
# Book Title

## About

Brief description of the book and its purpose.

## Metadata

| Field | Value |
|-------|-------|
| **Author** | |
| **Publisher** | |
| **Edition/Year** | |
| **Pages** | |
| **ISBN** | |

## Level

Beginner / Intermediate / Advanced / Expert

## Prerequisites

What the reader should know before starting this book.

## Key Topics

Bulleted list of main subjects covered.

## Tools & Technologies

Tools and technologies referenced or used in the book.

## What to Study First

Recommended chapters or sections to prioritize.

## What This Book Teaches

Summary of knowledge and skills gained.

## Strengths

What makes this book valuable.

## Weaknesses

Limitations or areas where the book falls short.

## Recommendation

Personal assessment and who should read this book.

## Official Resources

Links to official publisher page, author site, errata, etc.
```

## Guidelines

- **Do not upload or link to pirated content.** This includes PDF downloads, torrent links, or any unauthorized copies.
- **Write original notes.** Do not copy text from the books. Summaries must be in your own words.
- **Be accurate.** Do not invent information about books you haven't read. If something is unconfirmed, state it clearly.
- **Use consistent formatting.** Follow the existing Markdown style and naming conventions.
- **File naming:** Use lowercase with hyphens. Example: `web-application-hackers-handbook.md`

## Code of Conduct

- Be respectful and constructive in all interactions.
- Focus on educational value.
- Respect intellectual property rights.

## Questions?
