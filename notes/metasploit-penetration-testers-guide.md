# Metasploit: The Penetration Tester's Guide

## About
The authoritative guide to the Metasploit Framework, written by David Kennedy (creator of SET) and core contributors.

## Level
Intermediate

## Prerequisites
- Basic networking knowledge
- Linux command-line proficiency

## Key Topics
- Metasploit architecture and modules
- Information gathering, vulnerability scanning
- Exploitation techniques, Meterpreter post-exploitation
- Client-side attacks, social engineering with SET
- Writing custom Metasploit modules

## Tools & Technologies
Metasploit Framework, Meterpreter, Social-Engineer Toolkit, Nmap, Nessus

## What to Study First
Chapters 1-3 (basics), Chapters 4-5 (exploitation and Meterpreter), Chapter 11 (custom modules).

## What This Book Teaches
Complete mastery of the Metasploit Framework for professional penetration testing.

## Strengths
- Written by core Metasploit contributors
- Practical, lab-oriented approach
- Excellent Meterpreter coverage

## Weaknesses
- Published in 2011, some modules have evolved
- Specific exploits may be outdated

## Recommendation
Despite its age, the best dedicated Metasploit book. Core concepts haven't changed.
