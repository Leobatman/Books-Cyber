# The Hacker Playbook 3: Practical Guide To Penetration Testing

## About
The third installment of the Hacker Playbook series. Focuses on real-world red team scenarios with practical, hands-on exercises covering network attacks, web application testing, social engineering, and Active Directory compromise.

## Prerequisites
- Basic penetration testing knowledge
- Familiarity with Kali Linux and Metasploit
- Networking fundamentals

## Key Topics
- Red team methodology and planning
- Network exploitation and pivoting
- Web application attacks
- Active Directory enumeration and exploitation
- Social engineering campaigns
- AV evasion techniques
- Custom tool development

## Tools & Technologies
Kali Linux, Metasploit, Cobalt Strike, Empire, BloodHound, Mimikatz, Burp Suite

## What to Study First
The Pre-Game (Setup), Before the Snap (Recon), The Drive (Exploitation).

## What This Book Teaches
How to think and operate like a red teamer, not just a vulnerability scanner.

- Extremely practical with reproducible exercises
- Covers the full attack chain
- Regularly referenced by OSCP candidates

## Weaknesses

- Cobalt Strike examples require commercial license

One of the most practical offensive security books available. Build a lab and follow along with every exercise.
