# 07 — Red Team

Red team operations, adversary simulation, evasion techniques, and cloud attacks.

Red teaming goes beyond penetration testing. It simulates a real adversary — with stealth, persistence, and objective-driven operations. These books cover the mindset, methodology, and technical skills needed for red team engagements.

---

## Recommended Study Order

1. **Red Teaming Handbook (UK MoD)** — Strategic perspective on red teaming before diving into tools.
2. **RTFM: Red Team Field Manual** — Your constant companion during operations.
3. **Practical Anti-virus Evasion** — Critical skill for real-world engagements.
4. **Cloud Penetration Testing for Red Teamers** — Modern attack surfaces.
5. **Black Hat Python** (from [08-programming](../08-programming-for-security/)) — Build your own tools.

---

## Books in This Category

#### RTFM: Red Team Field Manual 1.0
- **Author:** Ben Clark
- **Level:** Advanced
- **Priority:** ⭐⭐⭐⭐⭐
- **Key Topics:** Windows/Linux command reference, networking commands, web attacks, database queries, PowerShell, Python one-liners
- **Why It Matters:** Not a book to read cover-to-cover — it's a quick reference manual for use during live operations. Essential for any red teamer's toolkit.
- **[Study Notes](../notes/rtfm-red-team-field-manual.md)**

#### Red Teaming Handbook (UK MoD, 2021)
- **Author:** UK Ministry of Defence
- **Level:** Intermediate
- **Priority:** ⭐⭐⭐⭐
- **Key Topics:** Red team planning, cognitive biases, structured analysis techniques, decision-making, team composition
- **[Study Notes](../notes/red-teaming-handbook.md)**

#### Practical Anti-virus Evasion
- **Author:** Daniel Sauder
- **Level:** Advanced
- **Priority:** ⭐⭐⭐⭐
- **Key Topics:** AV detection mechanisms, payload encoding, obfuscation, custom shellcode runners, compile-time evasion
- **[Study Notes](../notes/practical-antivirus-evasion.md)**

#### Cloud Penetration Testing for Red Teamers
- **Level:** Advanced
- **Priority:** ⭐⭐⭐⭐
- **Key Topics:** AWS/Azure/GCP security assessment, cloud misconfigurations, IAM attacks, serverless exploitation
- **[Study Notes](../notes/cloud-pentest-red-teamers.md)**

#### Red Team: How to Succeed by Thinking Like the Enemy
- **Author:** Micah Zenko
- **Level:** Intermediate
- **Priority:** ⭐⭐⭐
- **Key Topics:** Strategic red teaming (non-technical), organizational thinking, devil's advocacy
