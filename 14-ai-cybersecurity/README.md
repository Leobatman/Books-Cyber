# 14 — AI & Cybersecurity

Artificial intelligence in security operations, AI-powered tools, and adversarial attacks on AI systems.

An emerging and rapidly evolving category. As AI/ML becomes embedded in both defensive and offensive security, understanding how to leverage and attack these systems becomes increasingly important.

## Key Concepts

- **LLM (Large Language Model)** — Foundation of modern AI assistants and tools
- **Prompt Injection** — Attacking LLM-based applications via crafted inputs
- **Adversarial ML** — Techniques to fool machine learning models
- **AI Red Teaming** — Testing AI systems for security vulnerabilities
- **Deepfakes** — AI-generated synthetic media used in social engineering
- **MITRE ATLAS** — Framework for AI/ML threat modeling
