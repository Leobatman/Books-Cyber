# 02 — Network Security

Network attacks, protocol exploitation, scanning, and defense.

Understanding network security is essential for any security professional. These books cover everything from basic scanning with Nmap to advanced protocol-level attacks on enterprise infrastructure.

---

## Recommended Study Order

1. **Nmap Cookbook** — Learn the most important scanning tool first.
2. **Kali Linux Network Scanning Cookbook** — Expand beyond Nmap to full network assessment.
3. **Hacking Exposed: Network Security** — The comprehensive reference for network attack vectors.
4. **Hacking Exposed Cisco Networks** — Specialize in network device security.

---

## Books in This Category

### Essential

#### Hacking Exposed: Network Security Secrets & Solutions, 3rd Edition
- **Author:** Joel Scambray, Stuart McClure, George Kurtz
- **Level:** Intermediate
- **Priority:** ⭐⭐⭐⭐⭐
- **Key Topics:** Footprinting, scanning, enumeration, Windows/UNIX/Linux attacks, network devices, wireless, web apps, database
- **Why It Matters:** The network security encyclopedia. Organized by attack methodology with countermeasures for each technique.
