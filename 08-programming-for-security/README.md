# 08 — Programming for Security

Python, Bash, and JavaScript for offensive security, tool development, and automation.

Writing code is what separates a tool user from a tool builder. These books teach you to create custom exploits, automate reconnaissance, build backdoors, and extend existing frameworks — essential skills for advanced pentesting and red teaming.

---

## Recommended Study Order

### If you're new to Python:
1. **Python Crash Course** or **Automate the Boring Stuff** — Python fundamentals.
2. **Black Hat Python** — Offensive Python. The essential book.
3. **Violent Python** — More offensive recipes and techniques.
4. **Python for Offensive PenTest** — Practical pentest tool development.

### If you already know Python:
1. **Black Hat Python** — Start here directly.
2. **Violent Python** — Additional offensive recipes.
3. **Bash Shell Scripting for Pentesters** — Automate your Kali workflows.
4. **Coding for Penetration Testers** — Multi-language approach.
